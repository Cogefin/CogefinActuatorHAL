# アクチュエータとArduinoの互換性

## 表の読み方

表は周辺回路の名称，動作電圧，専属端子の形式や数の3個組となっており，接続端子の欄は数字/M/G/Sのうちのいずれかが入る．
数字の場合は，Grove形式コネクタの必要数．Mの場合は，Mega,Due,Gigaのようなボードの22番以降のコネクタ(18ピンx2列のコネクタ)に接続する
タイプのもの，GはGiga専用のデバイス，SはSPI I/Fを持つ回路であるため，クラシックタイプのシールド形式のボードになっている．

下の例はNセグメントLEDの事例でGroveのコネクタで利用できるのは，2種類のみで，そのうち一方は2つのコネクタを占有する．それ以外は
必要な端子数が多すぎるため，Mega系列のボードでしか利用できない．

|種別|動作電圧(V)|接続端子|
|---|---|---|
|[OSL12306-16-IRA(秋月電子)][OSL12306-16-IRA]|3.6～5.0(逆電圧:10)|M|
|[OSL20541-IR(秋月電子)][OSL20541IR]|2.1(逆電圧:5)|M|
|[OSL30561-IRA(秋月電子)][OSL30561IRA]|2.1(逆電圧:5)|M|
|[Grove - 4-Digit Display][Grove4DigitLED]|3.3～5.5|1|
|[3-Wire LED Module DFR0090][DFR0090]|不明1|2|

現状，配線上の問題でGiga専用となる周辺回路はGiga用のグラフィックディスプレイのみ．

### 注1
以下のプロトコルは受信側Arduinoでは認識できない/認識に失敗しやすい
- Bang Olufsen : 全く認識されない
- JVC : 全く認識されない
- LG2 : PULSE_DISTANCEと認識される
- Lego PF : プロトコル番号は認識されるが中身(各種パラメータ)が独自のエンコードがされており，確認が困難なため，中身の確認はしていない
- シャープ : bit単位の認識のミスでエラーになりやすい
- Denon : 認識に失敗する確率が高い
